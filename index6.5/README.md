
# Assignment 6.5 — Profile Card Mini-Project

## Objective
Create a responsive profile card using HTML and CSS.

## Features
- Profile image
- Name and professional role
- Short introduction
- Skills list
- Contact button
- Positioned student badge
- Responsive design

## CSS Concepts
- Box model: margin, padding and border
- Background and border-radius
- Position: relative and absolute
- Flexbox
- Media queries
- Meaningful CSS class names

## How to Run
1. Save index.html and style.css in the same folder.
2. Open index.html in a browser.
3. Resize the browser to test responsiveness.
4. Take a screenshot of the completed card.

## Submission
Submit index.html, style.css and a screenshot
of the finished profile card.
